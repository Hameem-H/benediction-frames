# Benediction Studio Showcase

You are designing a cinematic, minimal website for an independent film studio called "Benediction Studios".

Design direction:

- Inspired by A24(https://app.a24films.com/tabs/home), but NOT copied

- Films are the main focus

- Minimal UI, lots of empty space

- Black / near-black background

- Warm ivory typography (not pure white)

- Very subtle gold accents (optional)

- Large cinematic imagery

- Very little text

Tone:

- Warm, intimate, human

- Focused on faith, humanity, storytelling

Rules:

- Avoid clutter

- Avoid cards, borders, heavy UI

- Avoid bright colors

- Avoid long paragraphs

- Avoid generic layouts

Navigation:

- Only 3 items: FILMS | ABOUT | CONTACT

Goal:

Make the site feel like entering a film, not browsing a company website.
